Radar Karier na telefonie (przez Wi-Fi)

Telefon musi być w tej samej sieci co komputer (to samo Wi-Fi albo laptop na hotspocie z tego telefonu), a Radar Karier na komputerze musi być otwarty. Przy pierwszym włączeniu Windows może zapytać o dostęp do sieci — wybierz „Zezwól” (sieć prywatna).

Windows traktuje tę sieć jako publiczną — zapora może blokować telefon (strona „niedostępna”). Tak jest zwykle, gdy laptop łączy się przez hotspot z telefonu albo z nową siecią. Jak to zmienić:
  1. Na komputerze: Ustawienia Windows → Sieć i Internet → Wi-Fi → kliknij nazwę sieci → „Typ profilu sieci”: Prywatna.
  2. Albo: menu Start → wpisz „Zezwalaj aplikacji przez Zaporę systemu Windows” → „Zmień ustawienia” → przy Python / pythonw zaznacz też Publiczna → OK.
Potem odśwież stronę na telefonie.

Telefon zapamięta logowanie — następnym razem wystarczy otworzyć ten sam adres (dodaj go do ekranu głównego). Oferty, statusy, notatki, CV i filtry są wspólne z komputerem. Zmiana PIN-u wyloguje wszystkie telefony.

Jesteś na telefonie

Dostęp z telefonu włącza się i wyłącza na komputerze (Ustawienia → Telefon). Zmiany, które tu zrobisz — statusy, notatki, ustawienia — zapisują się na komputerze.
